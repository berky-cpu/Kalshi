# docs

- `REPORT.md` — the write-up: question, data, methods, results, conclusion, replication.
- `facts.md` — every contract, fee, index and feed fact the code depends on, with source URL and
  verification date. Anything not here is unverified.
- `brti-spec.md` — implementable specification of the CF Benchmarks BRTI methodology (v17.0).
- `feeds.md` — per-venue WebSocket contracts: endpoints, auth, schemas, gap detection, resync.
- `derivations/` — the math: settlement-averaging variance, BRTI replica stages, fee curve.
- `decisions/` — architecture decision records. ADR-001 settlement model, ADR-002 replica role,
  ADR-003 the economic gate, ADR-004 the conclusion.
- `research-brief.md` — the literature summary the project started from (October 2026).
