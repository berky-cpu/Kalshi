# notes

The research trail, in the order it happened. Nothing here is a result unless its review passed.

- `experiments/` — EXP-001 … EXP-010. Each note fixes its hypothesis, data split and evaluation
  protocol before the result, then records the result and the review verdict.
  EXP-000 is the template.
- `reviews/` — REV-001 … REV-037. Adversarial reviews of each roadmap item and experiment:
  look-ahead, fees, fill realism, statistics, unverified facts, safety.
- `figures/` — plots referenced by the experiment notes, one folder per experiment.
- `paper/` — outline of a working paper that was shelved (see `docs/REPORT.md` §4–5).

Reading order for the main result: EXP-002 → EXP-005 → EXP-007 → EXP-009 → EXP-010, then
`docs/decisions/ADR-003` and `ADR-004`.
