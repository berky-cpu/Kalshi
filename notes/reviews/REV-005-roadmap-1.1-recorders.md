## Round 1 — FAIL (3 blockers + 4 lower)
- **F1 [HIGH]** Bitstamp default gap rule treated `microtimestamp` as a +1 counter → false gap + resync on
  *every* message; test hid it with a synthetic field; +1 rule was invented (not in feeds.md).
- **F2 [HIGH]** Kraken checksum test **circular** — fixture checksums generated by the function under test;
  no external oracle (documented `1063832831` not reproduced). The sole BRTI gap detector was unvalidated.
- **F3 [HIGH, rule 3]** Kalshi adapter on wholly unverified protocol (0.4 never specced it) + synthetic fixture.
- **F4/F5 [MED]** trade-tape gaps forced a book resync (NotImplementedError path); `run_recorder` couldn't
  carry depth+aggTrade on one socket; Bybit trade-gap check claimed but not implemented (silent).
- **F6/F7 [LOW]** Kraken missing-checksum silently passed; Coinbase dead code + inconsistent resnapshot reset.

## Round 2 — PASS (all resolved; reviewer independently re-verified the two highest-stakes)
- **F1 FIXED** — default `event_id_field=None`; invented +1 check disabled; only `microtimestamp` regression
  is the default live-stream signal; test drives the DEFAULT config (no false gaps on clean fixture; regression fires).
- **F2 FIXED (genuinely non-circular)** — the Kraken L3 checksum guide's worked-example book (21 bids / 14 asks)
  was extracted and `kraken_crc32(...) == 1063832831` asserted. The reviewer **reimplemented the CRC from
  scratch without importing the code** and got the same `1063832831` over the same input — external oracle holds.
- **F3 — acceptably flagged, deferred** — Kalshi endpoints/auth/subscribe/`{type,sid,seq,msg}` frame VERIFIED
  from docs.kalshi.com; payload schema + seq semantics UNVERIFIED (/websockets 404'd) and flagged in multiple
  places; adapter tolerant. Split to **ROADMAP 1.1b**.
- **F4 FIXED** — `resync_on_gap` flag (trade tapes = False → log-only, no `needs_resnapshot`); `run_recorder`
  now routes each raw message to multiple processors (depth drives resync, trade logs only). No NotImplementedError.
- **F5 FIXED** — Bybit `publicTrade` now log-only gap on non-monotonic/duplicate `i` (forward skips unflaggable
  by design, documented). **F6/F7 FIXED.**
